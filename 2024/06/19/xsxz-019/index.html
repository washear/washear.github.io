夏商西周史话

“满天星斗”不成立

满天星斗和“四边强、中心弱”，是东亚中国的考古人挖错地域造成的认知偏差，是东亚中国的考古人为了掩盖自己挖错了地方的错误，提出来的借口，是误人误己的大骗局。

古籍记载

1.《尚书·禹贡》确立五服制度，以天子王畿为天下中心，甸、侯、绥、要、荒由内向外逐层展开，中心拥有最高礼乐与军政权威，四方为藩属朝贡区域。

2.《史记·五帝本纪》记载黄帝为天下共主，号令诸侯，征伐不享，天下秩序自共主的核心王畿向外辐射。

3.《逸周书》大量篇目，天子居于中土，四方部族前来朝贡述职，中央颁布政令，四方臣服听命。

4.《诗经》“溥天之下，莫非王土；率土之滨，莫非王臣”，反映三代固有的中心‑四方圈层天下观。

传世古籍共同指向一套中原中心式的圈层结构，但这里的“中土、中心”，并不是后世理解的东亚黄河中原，而是夏商西周实际王畿：西伯利亚东部。

满天星斗的观点

主流考古满天星斗学说，立足于东亚境内出土的考古材料：

距今5500‑4300年古国阶段，辽西红山、良渚、石家河、海岱龙山四边区域，城址、玉器、祭祀遗存发达；而东亚中原区域同期高等级遗存规模偏弱，呈现四边强，中心弱的格局。

考古人据此得出结论：华夏文明起源就在东亚本土，史前是多中心并立竞争；古籍的中心叙事是后世重构的产物，真实史前并不存在强大的中原核心。

底层预设：夏商西周的王朝本体就在东亚，考古发掘的东亚遗址，就是三代文明本体对应的遗存。

满天星斗说的不吻合

  1. 文献与考古的矛盾根源是发掘地点错位。古籍记载的王朝核心不在东亚，学界却一直在东亚大陆寻找夏商西周本部王都。在核心区外面做本体研究，自然得到“四边强、中心弱”的反常结果。

  2. 强行否定古籍固有的中心圈层叙事。为适配东亚考古现象，把原生的中心‑四方古史体系解释为后世篡改，没有考虑考古采样地点本身就不是王朝本体所在地。

  3. 无法解释东亚诸多高等级文化技术爆发式成熟。红山、良渚的玉礼、祭祀体系一出现就高度完备，东亚本土找不到完整循序渐进的演化链条。

  4. 研究逻辑倒置：用东亚外围据点的考古现象，去修正传世古籍记载，而不反思：是不是考古找错了王朝真正的核心地域。

5.古籍记载，夏商西周是有多个中心的竞争关系，但是身份明确就是夏商西周。东亚中国的良渚文化、红山文化、石茆文化、三星堆等，无法对应夏商西周的竞争者的身份。他们和夏商西周是同一时间、同一地点，又不是夏商西周，完美证明了夏商西周根本就不是在东亚中国的境内。

东亚体系理论的核心危害

  1. 发掘地点错位带来认知错位：一直在东亚寻找三代本体，实际只能挖到核心区之外的遗迹，由此诞生“满天星斗、四边强中心弱”这套模型，把外围现象当成文明本体真相。

  2. 否定古籍原生的中心说，将古史体系归为后世造伪，切断文献对上古史的指引作用。

  3. 混淆“文明辐射区”和“文明本体”，东亚所有遗址，无论发达与否，都只是外围，却被视作华夏文明的原生星辰。

  4. 形成闭环误导，不去思考真正的王畿不在东亚，持续在东亚内部反复推演文明起源，陷入原地循环。

西伯利亚东部体系的观点

  1. 夏商西周的真正王畿、文明本体位于西伯利亚东部。古籍里的“天下中心、中土”，对应的是西伯利亚东部，并非东亚黄河中原。因此古籍的圈层中心叙事本身完全成立，并不存在古史造假。

  2. 后世研究者把“天下中心”错误锁定在东亚中原，考古工作全部集中在中国境内。东亚只是三代的外围辐射地带，所以挖出来的结果就是：东亚的四边据点繁荣，东亚本地的中原地带反而实力平平，即所谓“满天星斗，四边强中心弱”。

  3. “四边强中心弱”仅仅是东亚这一片辐射区内部的局部现象，不是整个上古天下的真实格局。相当于只挖掘藩属领地，没有挖掘中央王朝本部，拿藩属的考古面貌，去定义中央王朝的历史。

  4. 东亚众多史前文化中，东北方向的红山文化地理位置最北，距离西伯利亚本部最近，受本部影响最深，面貌最接近本部，但依旧属于外围据点，不能等同于夏商西周本体。学术界完全忽略了红山文化和位于西伯利亚东部的夏商西周最为接近的这个线索。

  5. 核心判断：满天星斗的矛盾，本质是考古挖错了地方，不是古籍记载出错。

西伯利亚体系哪些吻合

  1. 古籍的中原（天下中心）叙事完全成立，只是这个中心地理坐标在西伯利亚东部，不需要解构、否定传世文献。

  2. 完美解释“四边强中心弱”的来源：只发掘外围辐射区，看不到真正的王朝本部，外围区域内部自然出现边角据点强盛、本地“中原”平淡的现象。

  3. 解释东亚各地高等级遗存的突然兴盛与崩塌：不需要假设各地独立诞生高等文明。

  4. 厘清研究边界：东亚考古只能说明东亚中国的文明发展，不能用来论证夏商西周本体制度；要验证古籍的中心说，目光应当投向西伯利亚东部，而不是局限东亚中国的境内。
